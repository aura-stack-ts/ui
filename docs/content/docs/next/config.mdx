```ts title="lib/auth.ts" lineNumbers

})
```

## What goes in `createAuth`

The `createAuth` function initializes the Aura Auth instance with configuration options for OAuth providers, session management, cookie handling, and security settings. For more details, read the [Aura Auth documentation](https://aura-stack-auth.vercel.app/docs/quick-start#auth-instance)

## What goes in `createAuthClient`

The `createAuthClient` function initializes the client-side Aura Auth instance that interacts with the server-side auth instance. For more details, read the [Aura Auth documentation](https://aura-stack-auth.vercel.app/docs/quick-start#client-instance)
