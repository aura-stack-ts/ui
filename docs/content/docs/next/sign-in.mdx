title: Sign In
description: A clean, minimalist sign-in card featuring email/password and OAuth 2.0 integrations powered by @aura-stack/next.
---

Four layout variants of the same `SignIn` block, built for the App Router. All four share the same props and call `useSignIn` from `@aura-stack/next`, which resolves `redirectTo` through `next/navigation`.
