Aura UI is a collection of re-usable components, blocks and hooks that you could copy and paste on your TypeScript applications, it is built on top of [Aura Auth](https://aura-stack-auth.vercel.app/) authentication library for TypeScript.

Aura UI is designed to be simple, flexible and easy to use. It provides a set of pre-built components that can be easily integrated into your application, allowing you to focus on building your application logic rather than worrying about the UI.

## Why Aura UI?

The collection was created as Clerk alternative for developers who want to build their own authentication system and UI components without relying on third-party services. It is open-source and free to use, making it a great choice for developers who want to have full control over their authentication and UI components and it is completely integrated with the Auth Auth library offered by Aura Stack.

The library is inspired by [shadcn/ui](https://ui.shadcn.com/) and [Tailwind UI](https://tailwindcss.com/), and it is built with TypeScript in the major of the supported frameworks and libraries by Aura Auth, and Tailwind CSS. It is designed to be easy to use and customize, allowing developers to quickly build beautiful and responsive user interfaces.
