title: Sign In
description: A clean, minimalist sign-in card featuring email/password and OAuth 2.0 integrations powered by @aura-stack/react-router.
---

Four layout variants of the same `SignIn` block, built for React Router. All four share the same props and call `useSignIn` from `@aura-stack/react-router`, which resolves `redirectTo` through `useNavigate`.
