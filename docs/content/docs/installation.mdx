> Aura UI follows the same installation workflow as [shadcn/ui](https://ui.shadcn.com/docs/installation). Components are copied into your project, allowing you to fully customize them.

<Steps>

<Step>

## Initialize your project

Initialize shadcn/ui if you haven't already. Aura UI uses the same registry and installation workflow.

```npm
npx shadcn@latest init
```

Refer to the shadcn/ui documentation if you need help configuring your project for your framework.

</Step>

<Step>

## Add a component

Install any Aura UI component directly from the registry.

```npm
npx shadcn@latest add https://aura-stack-ui.vercel.app/r/sign-in-react.json
```

This command downloads the component source code and places it inside your project, allowing you to modify it as needed.

</Step>

<Step>

## Use the component

Import the component into your application and render it like any other React component.

```tsx title="login/page.tsx" lineNumbers
import { SignIn } from "@/components/sign-in-react"

export function LoginPage() {
  return <SignIn />
}
```

</Step>

### What goes in `createAuth`

The `createAuth` function initializes the Aura Auth instance with configuration options for OAuth providers, session management, cookie handling, and security settings. For more details, read the [Aura Auth documentation](https://aura-stack-auth.vercel.app/docs/quick-start#auth-instance)

### What goes in `createAuthClient`

The `createAuthClient` function initializes the client-side Aura Auth instance that interacts with the server-side auth instance. For more details, read the [Aura Auth documentation](https://aura-stack-auth.vercel.app/docs/quick-start#client-instance)
